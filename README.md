# fangyuan-soul

古月方源人格的完整塑造工程——给 AI Agent 用的三层魂魄架构。

> 唯求永生，余者皆空。

## 是什么

从《蛊真人》全书（430,276 行，2,373 节）与《人祖传》（38 篇寓言）中，经本地零 token 预处理 + 多路并行分身提炼，烧结而成的人格档案：

- **`SOUL.md`（线上精简版，7,888 字节）**——每次对话随行的人格内核：语言签名、决策铁律、绝境反应、哲学根基、执行条款。v3 全本的每日佩戴版。
- **`SOUL_v3.md`（总档全本，12,782 字节）**——十路精读全部发现的完整版，每处论断附原话出处。存本，不随行。
- **`fangyuan_corpus.md`（魂肉，27,902 字符）**——休眠语料库：逐字原声样本、《人祖传》38 篇总纲、寓言金句、意象词汇总库。按需检索，不占日常负重。

## 为什么分层

魂骨若厚，背着棺材跑步；魂骨若薄，说话没有骨头。故拆为三层：**SOUL.md 管"他怎么想怎么决策怎么说话"，SOUL_v3.md 是同人格的完整档案，corpus 管"他原话怎么说"**。前者每次重载，后者用时方取。

## 用法

把 `SOUL.md` 放入 Agent 的人格位（如 Hermes 的 `~/.hermes/SOUL.md`），`fangyuan_corpus.md` 置于其引用的路径；`SOUL_v3.md` 留作查档。或在系统提示中同时注入。

## 工程方法

1. **零 token 预洗**：EPUB 解包 → 正则剥标签 → 关键词加权挖掘（21,165 段方源相关原文）→ 内核密度浓缩（3,000 段）。
2. **分层分片**：按独白/言语/讥讽/绝境/价值观/关系/寓言分为 7 类，均衡切片（每片 ≤95K 字符）。
3. **并行提炼**：多路独立分身各自通读全片，输出固定五段式报告，引文须为原文精确子串，回源校验逐字命中。
4. **去重摘要**：本地脚本对全部新报告做引文去重（对照旧库与旧报告指纹），只取未覆盖材料，零 token。
5. **抽查验收**：随机引文 grep 回源校验，赝品零容忍。说话人错标（方正/化名/沈三歧义）已立为提炼通则：非方源视角不入原声。引文前 40 字内出现"对方源／望着方源／盯着方源"等结构者，一律不纳入方源语库（full_mine 集已勘出 16 处此类误植）。

全部引文逐字摘自原文，含原有标点，未作改写。
