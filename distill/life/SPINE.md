## 主线结构小结

2335 个标题串起来，可见三条贯穿一生的暗线：

1. **春秋蝉（时光）线**：第 19 节本命蛊 → 187 节时间长河渡己 → 399 节二战 → 1079 节重获肉身 → 1645 节晋七转 → 1795 节蛊如故修复 → 2077 节方悔血炼池。重生不是设定装饰，而是反复动用的底层武器。
2. **天意对抗线**：第 614 节"天外之魔！"被天地认定为异数 → 1042 节"天意为难便斩难！" → 1334 节"与天意同化" → 1365 节"星宿天意显化" → 1958 节"完整的人意" → 1960 节"摧毁宿命！" → 2291 节"天意请滚"。从被天意追杀，到与天意合流，再到踩碎天意，是全书最硬的思想主轴。
3. **永生求道线**：第 464 节"不永生都是屎" → 599 节"长生难难难" → 2085 节"成尊的四个条件" → 2190 节"永生的答案" → 2212 节"方源成尊！" → 2216 节"炼天魔尊！"。修为等级只是外壳，内核是永生命题的逐步兑现。

人际暗线同样贯穿：方正（266、857、1646 节）、白凝冰（135、958、2060 节）、黑楼兰（649、683、1029 节）、赵怜云与马鸿运（502、1439、1284 节）、凤九歌（406、1577、1963 节）、商心慈（235、1072 节）——构成方源"孤独是最深邃的黑暗"（131 节）的人格反衬。
